## 🌟 About

VisionAssist is a real-time AI system that helps people with reduced vision navigate their environment through object detection and audio descriptions.

**📊 Global Impact:**
- 👁️ **2,200 million** people have vision impairment (WHO)
- 🌍 **1 billion** have moderate or severe distance vision impairment
- 📈 Projected to **double by 2050**
- 💼 **250 million** are of working age

## 🚀 Features

- ✅ **Real-time object detection** with YOLOv8 segmentation
- ✅ **Green mask visualization** around detected objects  
- ✅ **Audio descriptions** via Web Speech API
- ✅ **100% local processing** - no cloud dependencies
- ✅ **Accessible web interface**
- ✅ **Open source** and free forever

## 🛠️ Technologies

- **Backend:** Python, Flask, YOLOv8, OpenCV, NumPy
- **Frontend:** HTML5, Canvas API, Web Speech API, JavaScript
- **Computer Vision:** Ultralytics YOLO, Real-time processing
